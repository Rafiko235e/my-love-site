# Little Place For Us — GitHub Pages

## Upload
1. Upload every file/folder in this project to your GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save. GitHub will give you the website link.

## Add your own photos
Put your images inside `assets/photos/`.
Then replace the `YOUR PHOTO` blocks in `index.html` with:
`<img src="assets/photos/photo1.jpg" alt="Memory">`

## Add music
Put an MP3 named exactly:
`assets/music.mp3`

## Add voice note
Put an MP3 named exactly:
`assets/voice.mp3`

Everything else works without a server or database.
